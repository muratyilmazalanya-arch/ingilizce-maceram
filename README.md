# İngilizce Maceram
Çocuklar için Türkçe açıklamalı İngilizce öğrenme uygulaması.

## Yayınlama
GitHub deposunda Settings → Pages → Build and deployment → Deploy from a branch → Branch: main, folder: /(root) → Save.
Site adresi genellikle https://muratyilmazalanya-arch.github.io/ingilizce-maceram/ olur. GitHub Pages etkinleştirildikten sonra birkaç dakika bekleyin.

Android'de Chrome ile siteyi açıp menüden Ana ekrana ekle seçilebilir. İlerleme her tarayıcıda ayrı saklanır; cihazlar arası senkronizasyon yoktur.
